# Jaatni Birthday — GitHub Pages

Pure static HTML/CSS/JavaScript. No Node.js, Express, npm, or backend required.

## GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html` and the `photos` folder.
3. Repository → Settings → Pages.
4. Source: Deploy from a branch.
5. Branch: `main`, folder: `/ (root)`.
6. Save. GitHub will give you a Pages URL.

## Important
The birthday page is intentionally static so it can run directly on GitHub Pages.
The supplied YouTube link is opened after the 10th memory. Browsers/YouTube control autoplay behavior, so a normal YouTube page cannot be guaranteed to play invisibly in the background.
